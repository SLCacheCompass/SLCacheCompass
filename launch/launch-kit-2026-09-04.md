# Cache Compass launch kit — 2026-09-04

## Positioning
Cache Compass is a Windows inventory-management utility for Second Life residents using supported Firestorm Viewer releases. It helps residents search large inventories, surface duplicate/keyword/empty-folder candidates, review the results, and move only approved items to Second Life Trash. Cache Compass never empties Trash.

## Short product description
**Your inventory is the final boss. Cache Compass helps you find the clutter, review it, and move only what you approve.** Built for large Second Life inventories and supported Firestorm Viewer releases on Windows 10/11.
