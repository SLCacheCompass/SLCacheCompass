SUPPORT TOOL

Cache Compass Diagnostic

Use this support tool when Cache Compass Support asks you to collect diagnostic information about a problem with Firestorm, Cache Compass, or an inventory move.

This diagnostic does not make changes to Firestorm, Cache Compass, or your Second Life inventory. It does not require Administrator access. It collects basic Windows, display, Firestorm, Cache Compass, and recent diagnostic information so Support can investigate the problem.

Before you run it

Reproduce the issue first

  1. Open Firestorm and let your inventory finish loading.
  2. Open Cache Compass.
  3. If you use multiple monitors, place Firestorm and Cache Compass on the same monitor for this test.
  4. Reproduce the failed move once.
  5. Leave both Firestorm and Cache Compass open.

Run the diagnostic

Extract, run, and send the result

  1. Download the ZIP below.
  2. Extract the ZIP to a normal folder.
  3. Double-click Run Cache Compass Diagnostic.cmd.
  4. Wait for the diagnostic to finish.
  5. Windows should highlight CacheCompass-Diagnostic.txt.
  6. Attach that TXT file to your reply to Cache Compass Support.

The download contains the diagnostic script, a simple launcher, and a README with the same instructions shown above.

Download Support Diagnostic

Windows may display a security warning because the package contains script files used to collect diagnostic information. The diagnostic does not install software or make system changes.
